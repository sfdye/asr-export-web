# asr-export-web

Web app for Avenue South Residence residents to bulk-download their Habitap
documents as a single zip, ahead of the Habitap → iCondo migration.

Status: milestones 1–3 complete (connectivity spike, export server, wizard
UI) — verified end-to-end against a mock Habitap and a real account login.
Deployment (Docker/Caddy) is next.

Sister project: [asr-export](https://github.com/sfdye/asr-export) — the
zero-server Python CLI.
